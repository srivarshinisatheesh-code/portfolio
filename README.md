# Sri Varshini S — Developer Portfolio

## Open locally
Keep `index.html` and `profile.png` in the same folder, then double-click `index.html`.

## Publish with GitHub Pages
1. Create a GitHub repository named `your-username.github.io` (replace with your actual GitHub username).
2. Upload both `index.html` and `profile.png` to the repository root.
3. In the repository, open Settings → Pages.
4. Under Build and deployment, select Deploy from a branch, choose `main` and `/ (root)`, then Save.
5. After publishing, your site will be available at `https://your-username.github.io`.

## Before publishing
- Confirm your GitHub username and profile URL.
- Add verified GitHub repository links for each project when available.
- Check the contact details and project descriptions.
